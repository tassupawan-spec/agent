Annotations — S6 Deactivate replaces Delete

ต้องยืนยัน PO/BA ก่อน implement จริง
What changed from the prototype
Prototype: icon "ลบ" (ถังขยะ) ในคอลัมน์รายละเอียด → คลิกแล้วลบแถวทันที ไม่มี confirm. PO ปฏิเสธพฤติกรรมนี้เพราะกระทบ Report ที่อ้างอิง slot เดิม (hard-delete ทำลายข้อมูลย้อนหลัง)
Design decision taken here
คอลัมน์ "รายละเอียด" เหลือปุ่มเดียวคือ "แก้ไข" (ดินสอ, ghost icon button 32×32). ไม่มีไอคอน "ลบ" อีกต่อไป การ "เลิกใช้งาน" ทำผ่าน toggle สถานะ (เปิด→ปิด) ในคอลัมน์ "สถานะ" แทน ซึ่งของเดิมมีอยู่แล้วใน S1/S7 — ไม่ต้องสร้าง component ใหม่
Why the icon slot at row 1 is shown ghosted
กรอบเส้นประในแถวลำดับ 1 คือภาพประกอบทางเลือกที่ยังไม่เลือก (ตัวเลือก B: เก็บไอคอนไว้แต่ปิดใช้งาน/restricted เมื่อ slot มีประวัติการใช้งานแล้ว) — ไม่ใช่ค่า default ที่แนะนำ ดู "Open item" ด้านล่าง
Open item — needs PO/BA sign-off
งานออกแบบนี้ default ไปที่ตัวเลือก A (เอาไอคอน "ลบ" ออกจากตารางทั้งหมด ไม่มีเงื่อนไข) ตามคำแนะนำใน Screen Flow §5 ข้อ 1 เพราะปลอดภัยที่สุดและไม่ต้องมี business rule เพิ่มเรื่อง "zero historical usage". ตัวเลือก B (เก็บไอคอนไว้แต่จำกัดสิทธิ์เฉพาะ slot ที่ยังไม่เคยถูกใช้ในรายงาน) ยังไม่ได้ตัดสินใจ — ต้องยืนยันกับ PO/BA ก่อนส่งต่อ angular-implementer
Row status column stays functional
Toggle เปิด/ปิด ในตารางยังทำงานปกติเหมือน S1 — คลิกแล้วเปลี่ยนสถานะทันที ไม่มี confirm (คงพฤติกรรมเดิมตาม PO decision #3, เห็นรายละเอียดเพิ่มใน S7)
Hit target
ปุ่ม "แก้ไข" ขนาด 32×32px ผ่านเกณฑ์ WCAG 2.5.5 ขั้นต่ำ 44×44 — ไม่ผ่านตามตัวเลขตรงๆ (ดูตาราง compliance ใน README สำหรับรายละเอียดและ mitigation)
