ยืนยันการเปลี่ยนแปลงข้อมูล

คุณต้องการบันทึกการเปลี่ยนแปลงค่า Pool และเวลารอบจัดส่งนี้หรือไม่?

Annotations — S8 Save Confirm

Matches prototype 1:1
ไม่มี PO decision ให้เปลี่ยนแปลงหน้านี้ — คงไอคอน warning + heading + body + ปุ่ม "ยกเลิก"/"ยืนยันบันทึก" ตามที่สังเกตในต้นแบบ ใช้ token dialog anatomy จาก DESIGN.md §10 ([proposed], ยังไม่เคย verify กับ Ref/ จริง)
No toast on confirm — PO confirmed
คลิก "ยืนยันบันทึก" → ปิด dialog กลับไป S1 โดยไม่มี toast ใดๆ (ต่างจาก S7 ที่มี toast เฉพาะตอน toggle สถานะ ปิด→เปิด). ค่าที่เปลี่ยนทั้งหมด (ฟอร์ม Pool + slot ที่เพิ่ม/แก้/toggle ระหว่าง session) ถูก commit ที่จุดนี้
Cancel — inferred, standard pattern
"ยกเลิก" → ปิด dialog กลับไป S1 โดยไม่ save (pattern มาตรฐาน, ยังไม่ re-test แยกในต้นแบบแต่ไม่มีข้อโต้แย้งจาก PO)
Focus & keyboard
เปิด dialog → focus ไปที่ "ยกเลิก" (ปุ่ม non-destructive เป็น default focus เพื่อป้องกันการกด Enter พลาด). Esc = เทียบเท่า "ยกเลิก". Focus trap ในกรอบ dialog, ปิดแล้ว focus กลับไปที่ปุ่ม "บันทึก" ที่ page footer
Contrast check
Heading --text-primary #212121 บน --surface-raised #ffffff → 16.1:1 ✅. Body --text-secondary #5a6b7f บนขาว → 5.9:1 ✅ (≥4.5:1). Warning icon --status-warning-icon #ffb946 บนขาว → 1.8:1 (known issue เดิมจาก DESIGN.md §3.5 — ใช้เป็น icon ประกอบ heading ข้อความเข้มเสมอ ไม่ใช้สื่อความหมายเดี่ยวๆ)
