Annotations — S3 Filter Panel

Toggle vs. apply
คลิก "ตัวกรอง" ครั้งแรก → panel เลื่อนลงมาแทรกใน card (ไม่ใช่ modal), ดัน table ลง. คลิก "ตัวกรอง" ซ้ำ (ปุ่มเดิม) → แค่ยุบ panel เท่านั้น ไม่ apply ค่าใดๆ. เฉพาะปุ่ม "ใช้ตัวกรอง" เท่านั้นที่ apply — ยืนยันโดย PO แล้ว ไม่ต้องเปลี่ยน
Filter fields
3 dropdown: ช่องทางการขาย (ทั้งหมด/SD/WA/XB/XC), Delivery Option (ทั้งหมด/Delivery/Pickup), Slot Type (ทั้งหมด/Normal/VIP) — ใช้ pattern Select เดิมจาก DESIGN.md §10 (mat-select ผ่าน outline field)
Badge count
ปุ่ม "ตัวกรอง" เปลี่ยนเป็น active (bg --surface-selected) และแสดง "(n)" เป็นข้อความต่อท้าย label เมื่อมี filter ใช้งานอยู่ — ไม่ใช้ pill badge วงกลม (สอดคล้องกติกา forbidden pill-shaped badge). ค่า n = จำนวน field ที่ตั้งค่าไม่ใช่ "ทั้งหมด"
Active filter chip — new pattern
Chip "Slot Type: VIP" ไม่มีอยู่ใน DESIGN.md §10 ปัจจุบัน (มีแต่ status-indicator ซึ่งห้ามเป็น pill). ประกอบจาก token ที่มีอยู่แล้วเท่านั้น (--surface-selected, --text-brand, --radius-sm, --space-*) ไม่มี token ใหม่ — แนะนำให้ design-system-guardian เพิ่มเป็น "Filter chip" component ใน §10 อย่างเป็นทางการ
Clear
"ล้าง" → รีเซ็ตทั้ง 3 dropdown เป็น "ทั้งหมด", เอา chip และ badge count ออก, table กลับมา 10 แถวเดิม, panel ยังเปิดค้างอยู่ (ไม่ยุบ)
Keyboard
Tab ผ่าน 3 select ตามลำดับ, Enter/Space เปิด dropdown, Arrow Up/Down เลือกตัวเลือก, Esc ปิด dropdown โดยไม่เปลี่ยนค่า. "ล้าง"/"ใช้ตัวกรอง" tabbable, Enter สั่งงาน
Contrast check
Chip: --text-brand #334d6e บน --surface-selected #eef1f5 → 8.4:1 ✅. Badge label: --action-secondary-text #334d6e บน --surface-selected #eef1f5 → 8.4:1 ✅
