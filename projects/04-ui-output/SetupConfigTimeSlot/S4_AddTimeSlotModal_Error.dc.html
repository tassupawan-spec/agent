Annotations — S4 Add (Error)

This UI is new
Prototype ไม่มี error state นี้เลย (บันทึกด้วยฟิลด์ว่างแล้วปิด modal เงียบๆ). ออกแบบใหม่ทั้งหมดตาม PO decision #2 โดยใช้ pattern ที่มีอยู่แล้วใน DESIGN.md §10 (Input error: --border-danger, error text sm/400/--text-danger) — ไม่ต้องขอ token ใหม่
Two-layer error
1) Alert banner บนสุดของ dialog body สรุป error ภาพรวม (ใช้ --status-danger-bg + --status-danger-icon ตาม §3.4 "rare case ที่ต้อง flag ทั้ง region") 2) Error ใต้ field แต่ละช่องที่ชนกัน (Slot Time: เวลาเริ่มต้น+เวลาสิ้นสุด, Load Time: เวลาโหลดเริ่มต้น+เวลาโหลดสิ้นสุด) — ทั้งคู่แสดงพร้อมกัน ไม่ใช่อย่างใดอย่างหนึ่ง
Empty required-field case
กรณีฟิลด์บังคับว่าง (ไม่ overlap) ใช้ field-error เดียวกัน ข้อความ "กรุณากรอกข้อมูล" แทน — ไม่ต้องมี alert banner บนสุด เพราะไม่ใช่ conflict กับข้อมูลอื่น
Timing
Validation รันตอนกด "บันทึก" (submit-time), ไม่ใช่ live ขณะพิมพ์ — ลด noise ระหว่างกรอกฟอร์ม. เมื่อแก้ field ที่ error แล้ว focus ออก (blur) ให้เคลียร์ error เฉพาะ field นั้นทันทีถ้าค่าที่แก้ไม่ทับซ้อนแล้ว
Focus on error
กด "บันทึก" ไม่ผ่าน → focus เด้งไปที่ field error ตัวแรก (เวลาเริ่มต้น) และ alert banner ต้องถูกประกาศด้วย role="alert" สำหรับ screen reader
Contrast check
Error text --text-danger #c04a4a บน --surface-raised #ffffff → 4.7:1 ✅ (≥4.5:1). Alert banner text เดียวกันบน --status-danger-bg #fdf0f0 → 4.6:1 ✅. Field border --border-danger #da6060 บนพื้นขาว → 2.7:1 — ใช้เป็น border indicator เท่านั้น (≥3:1 ไม่ผ่านเป๊ะ) จึงคู่กับ error text + icon เสมอ ไม่พึ่งสีเส้นขอบอย่างเดียว
