How to read: Solid blue = request / main flow · Gray dashed = response (ตอบกลับ) · Orange dashed = Void Booking · Yellow diamond = decision / routing. Column headers are frozen while you scroll.

Shipment creation (steps 74–75): right after TMS receives the Sale Order, a shipment is created via one of two flows — flow 1 (74) run optimize → import, or flow 2 (75) manual tick order. Both feed the check "created before Pick Confirm?" (41): if created before Pick Confirm → NEW_SHIPMENT (14070 / 14071) (42), which becomes Truck Confirm (44) on PICK_CONFIRM; if Pick Confirm already happened (created after) → Truck Confirm directly.

Delivery (Phase 5b–6b): At Truck Confirm TMS sends CONFIRM_DELIVERY (→SPC→CFW) + a Recalculation round-trip, triggers POS/e-Tax if is_invoice_on_delivery = Yes, and prints Tax Invoice/ABB for the driver. Check-in Store → CHECKIN-STORE (to SPC only). Driver enters QTY LOAD → Loader approves (reject = re-enter) → Recalculation; if QTY LOAD ≠ PICK_CONFIRM, Delivery Order + Truck Manifest auto-print. Then OUT_FOR_DELIVERY → SHIPPING → close job (Recalculation). Settlement: no extra payment → DELIVERED; otherwise payment (driver or O2O store) then DELIVERED → triggers POS / e-Tax (24–29).

QC (Phase 6c): after DELIVERED (70) TMS runs a QC step (78) → QC pass (80) or QC fail (re-QC loop). Manual Create Order (Alt): besides receiving the Sale Order from SPC, an order can be created manually on TMS via the Offline Channel (81–97). After Planning Step the order goes to Create Shipment (74/75) and these orders become Truck Confirm directly, then enter the normal delivery flow.
